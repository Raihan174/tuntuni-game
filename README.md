# টুনটুনি আর রাজা — Android অ্যাপ

এই ফোল্ডারে গেমটির পুরো Android প্রজেক্ট আছে। নিচের যেকোনো একটি উপায়ে APK বানানো যায়।

## উপায় ১: GitHub দিয়ে (কম্পিউটারে কিছু ইনস্টল লাগবে না, বিনামূল্যে)

1. github.com এ একটা অ্যাকাউন্ট খুলুন (আগে না থাকলে)।
2. উপরে **+ → New repository** চাপুন। নাম দিন যেমন `tuntuni-game`, তারপর **Create repository**।
3. নতুন repository পাতায় **uploading an existing file** লিংকে চাপুন। এই zip খুলে ভেতরের সব ফাইল ও ফোল্ডার টেনে এনে ছেড়ে দিন, তারপর **Commit changes**।
4. খেয়াল করুন `.github/workflows/build-apk.yml` ফাইলটা উঠেছে কিনা (কিছু কম্পিউটারে লুকানো ফোল্ডার বাদ পড়ে যায়)। না উঠলে **Add file → Create new file** চাপুন, নামের ঘরে `.github/workflows/build-apk.yml` লিখে ফাইলের লেখাটা পেস্ট করে **Commit** করুন।
5. **Actions** ট্যাবে যান। "Build APK" চলা শুরু করবে (না করলে **Run workflow** চাপুন)। ৩–৫ মিনিট পর সবুজ টিক আসবে।
6. সেই রানে ঢুকে নিচে **Artifacts** থেকে `tuntuni-apk` নামিয়ে নিন। zip খুললে `app-debug.apk` পাবেন।
7. APK ফোনে পাঠিয়ে খুলুন। ফোন "অজানা উৎস" (Unknown sources) থেকে ইনস্টলের অনুমতি চাইলে দিন।

## উপায় ২: Android Studio দিয়ে

1. Android Studio ইনস্টল করে **Open** দিয়ে এই ফোল্ডার খুলুন।
2. প্রথমবার সব কিছু নামাতে কিছুক্ষণ লাগবে।
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)** চাপুন।
4. APK পাবেন `app/build/outputs/apk/debug/` ফোল্ডারে।

## অ্যাপে কী আছে

- পুরো গেম অ্যাপের ভেতরেই থাকে, ইন্টারনেট ছাড়াও খেলা যায় (ইন্টারনেট থাকলে শুধু সুন্দর বাংলা ফন্ট আসে)।
- ফোন আড়াআড়ি (landscape) করে খেলা হয়, পর্দা পুরো জুড়ে থাকে, খেলার সময় পর্দা নিভে যায় না।
- ফোনে Google-এর বাংলা কণ্ঠ থাকলে অ্যাপ গল্প আর শব্দ বাংলায় পড়ে শোনায়। না থাকলে Settings → ভাষা ও ইনপুট → Text-to-speech থেকে বাংলা ভাষা নামিয়ে নিন।
- অগ্রগতি, জমানো টাকা আর দোকানের কেনা জিনিস ফোনে সেভ থাকে।

এটি "debug" APK, নিজের ও পরিচিতদের ফোনে ইনস্টলের জন্য ঠিক আছে। Google Play-তে দিতে চাইলে আলাদা "release" সাইন করা লাগবে।
